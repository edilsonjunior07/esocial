# Mapa Fácil do eSocial - Página de Vendas Oficial

Repositório da página de vendas oficial do produto **Mapa Fácil do eSocial**.
Configurado e otimizado para deploy estático via **Cloudflare Pages**.

## Estrutura de Arquivos
- `index.html` — Landing page de alta conversão (HTML, CSS e JavaScript inline)
- `assets/` — Imagens, mockups 3D e elementos visuais da página de vendas
- `_redirects` — Regras de redirecionamento e SPA para o Cloudflare Pages
