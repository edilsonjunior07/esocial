## 📋 Descrições Oficiais de Cadastro (Limite Exato ≤ 200 Caracteres)

Copie e cole diretamente no campo de descrição da sua plataforma (Kiwify, Hotmart, Cakto, Eduzz):

### 1. Produto Principal (138 caracteres)
```text
14 fluxogramas visuais em PDF para dominar todos os eventos S-xxxx e rotinas de Departamento Pessoal sem multas e sem manuais longos.
```

### 2. Order Bump 01 (150 caracteres)
```text
25 modelos editáveis de advertências, comunicados e notificações trabalhistas prontos para preencher e usar no dia a dia do seu Departamento Pessoal.
```

### 3. Order Bump 02 (130 caracteres)
```text
Planilha automatizada para cálculo de aviso prévio proporcional, prazos de envio do eSocial e vencimentos de DARF e FGTS Digital.
```

## 🎯 Guia Rápido de Lançamento (4 Passos)

1. **Subir a Página de Vendas:**
   - Faça upload dos arquivos da pasta `01_PAGINA_DE_VENDAS/` para sua hospedagem (Netlify, Vercel, Hostinger ou Cloudflare Pages).
   - Insira o link do seu checkout nos botões de compra.
2. **Cadastrar na Plataforma (Kiwify / Cakto / Hotmart):**
   - Cadastre o produto principal e os 2 order bumps usando as descrições de ≤ 200 caracteres acima.
   - Atribua as capas 3D correspondentes (`capa_3d_produto_principal.png`, `capa_3d_kit_25_modelos.png`, `capa_3d_planilha_prazos.png`).
3. **Configurar a Área de Membros / Entrega:**
   - Entregue o PDF do Produto Principal + os 5 PDFs de Bônus.
   - Adicione o PDF de Modelos (OB1) e a Planilha Excel (OB2) como entregáveis adicionais para quem marcar os checkboxes.
4. **Subir os Criativos no Gerenciador de Anúncios:**
   - Use os 4 criativos da pasta `02_CRIATIVOS_E_ANUNCIOS/` em uma campanha CBO/ABO com os públicos e copys detalhados em `06_ESTRATEGIA_E_CADASTRO/02_estrategia_trafego_e_campanha.md`.
